Que datos tratamos

The Vault Escape puede tratar los siguientes datos cuando decides iniciar sesion o utilizar funciones personales:

  • Identificador tecnico de usuario de Firebase y datos basicos de Google necesarios para el inicio de sesion.
  • Nombre publico o alias elegido en el perfil, y foto de Google si decides mostrarla.
  • Favoritos, salas pendientes, salas hechas, tiempo completado, grupos privados e invitaciones.
  • Votos, puntuaciones por categorias, resenas publicas y contenido que publiques voluntariamente.
  • Datos tecnicos imprescindibles para que Firebase, GitHub Pages y el navegador puedan prestar el servicio.

Finalidades

Usamos estos datos para identificar tu cuenta, guardar tus listas personales, permitir grupos privados, mostrar resenas publicas, calcular rankings, mantener seguridad tecnica y mejorar el funcionamiento de la web.

Datos visibles para otras personas

Las resenas, puntuaciones y el nombre publico asociado a una resena pueden mostrarse a cualquier visitante. No publicamos tu correo electronico. Los grupos escapistas son privados para sus miembros.

Conservacion

Los datos se conservan mientras mantengas tu cuenta o mientras sean necesarios para prestar el servicio. Puedes pedir la eliminacion de tus datos. Algunas copias tecnicas o historicas pueden mantenerse durante el tiempo estrictamente necesario por seguridad, cumplimiento legal o mantenimiento.

Servicios de terceros

El inicio de sesion se realiza con Google Firebase Authentication. Los datos personales y funcionales se almacenan en Firebase Realtime Database. La web se sirve mediante GitHub Pages. Tambien pueden cargarse recursos tecnicos como fuentes o mapas desde proveedores externos cuando sean necesarios para mostrar correctamente la web.

Derechos

Puedes solicitar acceso, rectificacion, supresion, oposicion, limitacion del tratamiento, portabilidad o retirada del consentimiento escribiendo a isaacborras@msn.com. Tambien puedes contactar por Instagram en @thevault_escape. Si consideras que no se ha atendido correctamente tu solicitud, puedes reclamar ante la Agencia Espanola de Proteccion de Datos.

Menores de edad

Si una persona menor de edad utiliza funciones de cuenta, debe hacerlo con autorizacion de sus representantes legales.

Cambios en esta politica

Esta politica puede actualizarse para reflejar cambios tecnicos, legales o funcionales. La fecha superior indicara la version vigente.
