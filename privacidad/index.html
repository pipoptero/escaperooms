Qué datos tratamos

The Vault Escape puede tratar los siguientes datos cuando decides iniciar sesión o utilizar funciones personales:

  • Identificador técnico de usuario de Firebase y datos básicos de Google necesarios para el inicio de sesión.
  • Nombre público o alias elegido en el perfil, y foto de Google si decides mostrarla.
  • Favoritos, salas pendientes, salas hechas, tiempo completado, grupos privados e invitaciones.
  • Votos, puntuaciones por categorías, reseñas públicas y contenido que publiques voluntariamente.
  • Datos técnicos imprescindibles para que Firebase, GitHub Pages y el navegador puedan prestar el servicio.

Finalidades

Usamos estos datos para identificar tu cuenta, guardar tus listas personales, permitir grupos privados, mostrar reseñas públicas, calcular rankings, mantener seguridad técnica y mejorar el funcionamiento de la web.

Datos visibles para otras personas

Las reseñas, puntuaciones y el nombre público asociado a una reseña pueden mostrarse a cualquier visitante. No publicamos tu correo electrónico. Los grupos escapistas son privados para sus miembros.

Conservación

Los datos se conservan mientras mantengas tu cuenta o mientras sean necesarios para prestar el servicio. Puedes pedir la eliminación de tus datos. Algunas copias técnicas o históricas pueden mantenerse durante el tiempo estrictamente necesario por seguridad, cumplimiento legal o mantenimiento.

Servicios de terceros

El inicio de sesión se realiza con Google Firebase Authentication. Los datos personales y funcionales se almacenan en Firebase Realtime Database. La web se sirve mediante GitHub Pages. También pueden cargarse recursos técnicos como fuentes o mapas desde proveedores externos cuando sean necesarios para mostrar correctamente la web.

Derechos

Puedes solicitar acceso, rectificación, supresión, oposición, limitación del tratamiento, portabilidad o retirada del consentimiento escribiendo a isaacborras@msn.com. También puedes contactar por Instagram en @thevault_escape. Si consideras que no se ha atendido correctamente tu solicitud, puedes reclamar ante la Agencia Española de Protección de Datos.

Menores de edad

Si una persona menor de edad utiliza funciones de cuenta, debe hacerlo con autorización de sus representantes legales.

Cambios en esta política

Esta política puede actualizarse para reflejar cambios técnicos, legales o funcionales. La fecha superior indicará la versión vigente.
